How to Use Your API Key Once Approved
Export API Endpoint

Fetch your pre-filtered records directly in JSON, Excel, or CSV format:

GET /api/v1/client/export
Header: X-API-Key: YOUR_APPROVED_API_KEY
Optional URL params: &format=excel or &format=csv
Import API Endpoint

Ingest dataset records directly into the system database:

POST /api/v1/client/import
Header: X-API-Key: YOUR_APPROVED_API_KEY
Body: [ {"first_name": "John", "email_address": "john@example.com"} ]
